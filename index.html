【学习复盘】首次接触CS:APP：DataLab复盘

引言：CSAPP中讲述了很多底层的原理，这很吸引人（学起来bushi），所以主包打算在一开学就开始搞这个东西，用了一个星期左右在课余学习了一下这些诡异的规则然后做完上面的题目，主要想要记录一下自己的一些思路，也算是push自己去做一些输出。

0、一些主包注意到的东西

这个鬼lab并不友好，它限制了很多条件判断符的使用，仅在实在没招了才给人用ifelse语句，因此需要格外注意注释部分防止违反规定。

1、整数部分

bitXor函数（按位异或）

同样进行了限制（只允许使用&和~），那么就分情况写：按位异或是相同时为0，不同为1，那么我们可以让x和y分别取反，这样不等的位置始终为0，但是相等的位置一定有一次为1，对两次取反后做按位与操作可以把不等的情况转化为0，相等情况变为1，再取反就行了。

allOddBits函数（奇数位为1）

这一题需要构造掩码，（也是非常辛苦的学习了一下16进制然后发现自己的进制方面简直达芬），用一个0xAA构造一个奇数位是1，偶数位全是0的掩码，之后用按位或来做原数据处理就行，这里算是掩码的开端，理解了后面会感觉挺顺。

isAsciiDigit函数

需要判断x是否属于（0x30,0x39）区间，但是肯定是不给用大于小于号的，所以我们可以用加减法进行判断。

conditional函数

这个可能是主包做完最力竭的函数之一。要求是如果x为0就输出z，1就输出y，所以第一步取双重否定就能得到结果。但是要怎么得到结果呢？是的又是掩码。注意到如果把这个结果取反加一，那么会得到两个结果：结果为1时，会得到全为1的掩码；结果为0时掩码是全为0的。那么就可以用来做一个判断处理。类似于上面的allOddBits。

logicalNeg函数

这个函数也是孩子认为绝顶妙的一个。首先给x做取反加1的操作（即取相反数）：如果x是正数，那么取反之后符号位就是1，此时再和原来的x取按位或，右移31位后就变成全为1的掩码，加1变0；而如果是0则会得出来1。

howManyBits函数

这个函数是要求多少位才能表示出x，需要用到一点二分的思想，不断的二分查找最高位1的位置。如果让符号位右移31位，再和原数异或，将得到正数不变，负数取反。正数找最高1即可，再加一位表示符号；负数需要记到符号位，不过最高位0后全是符号位，所以也需要找到最高位的0再加1就行了。所以我们和符号位取异或的操作完全可以。

浮点部分

整数部分是属于压榨操作符的操作上限，浮点数部分(Float)感觉更像是对 IEEE 754 的考察。虽然操作空间('if-else’和任意常数)放大了，但是必须处理好符号位(s),阶码(exp)和尾数(frac).

绝大部分开头都可以这样子提取这些位置：

1. 乘2函数(floatScale2)

这个是要求‘2*f’的数值的函数，在浮点数表示标准下(IEEE 754),肯定不能无脑移位的。

思路（分类讨论）

既然要处理浮点数，那就要根据阶码分情况讨论它是哪种类型的数。

  1. 特殊值（exp == 0xFF）： 无论是无穷大还是NaN，乘以 2 仍是本身，原样返回就行。
  2. 非规格化数（exp == 0）： 此时数值极小，尾数部分没有隐藏的1，乘以2只要保留符号位，将尾数左移一位就可以了，如果溢出也可以到阶码部分。
  3. 规格化（就是介于上两个情况中间的）： 位数不能变，阶码加一。

2. 类型转换：floatFloat2Int

要求实现(int) f的转换，其实这个就是需要非常熟悉浮点数的表示标准，按部就班替换。

思路

我们需要还原真实的阶码值 E = exp - 127。

  1. **下溢出（E<0）：**浮点数绝对值小于1，直接向下取到0就行。
  2. 上溢出（E>=31）： 32 位有符号整数最大只能表示到 2^31 - 1。阶码达到或超过 31 直接越界，按题意返回溢出标志 0x80000000u。
    正常转换： 为尾数补充隐藏的 1（即 frac = frac | 0x800000）。
    • 若 E < 23，说明小数部分有赘余，需右移截断：frac >>= (23 - E)。
    • 若 E > 23，说明整数部分还没移完，需左移放大：frac <<= (E - 23)。

3. 数学与位级的桥梁：floatPower2

求 2^x 的浮点数表示。这题相对轻松，是对阶码偏移量（Bias = 127）的直接应用。

核心思路

  • 若 x 太小（x < -149）：连最小的非规格化数都无法表示，返回 0。
  • 若 x 适中（-126 <= x <= 127）：直接计算 x + 127 放入 exp 字段，尾数全填 0。
  • 若 x 极大：返回无穷大的位模式（即 exp = 0xFF, frac = 0）。
